# Pomodoro Sederhana

Timer Pomodoro satu halaman, tanpa framework dan tanpa build. Cukup satu file `index.html`.

## Fitur
- Siklus fokus (default 25 menit) dan istirahat (default 5 menit)
- Durasi bisa diubah
- Tombol Mulai/Jeda, Reset, dan Lewati
- Hitungan sesi fokus per hari (disimpan di browser)
- Sisa waktu tampil di judul tab

## Cara pakai
Buka `index.html` di browser, atau jalankan server statis:

```bash
python3 -m http.server 8000
```

Lalu buka http://localhost:8000.
